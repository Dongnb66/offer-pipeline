# offer-pipeline 求职流水线助手

从「我是谁」到「面试进场」的本地求职流水线：**画像 → 能力推断 → 方向推荐 → JD 分析 → 打招呼初稿 → 投递台账 → 面试备战 → 简历直填包**，一个闭环，数据全部存在本机浏览器。

单文件前端（纯 HTML/CSS/JS，无外部依赖、无框架、无构建）+ 可选零依赖 Node 本地服务（面经抓取 / AI 润色）。

## 为什么做这个

市面上的求职工具分两种：一种帮你"自动化投简历"，一种帮你"把项目做出来"。这两种都有致命问题：

- **自动代投**违反招聘平台用户协议，封号风险由用户承担；
- **平台代做项目**，用户简历上写的是自己答不出设计决策的项目，面试一问"为什么这么选型"就露馅，且全平台项目同质化。

所以本项目立了三条红线（也是产品哲学，见应用内「三不原则」页）：

1. **不收账号密码** —— 将来接推送只走 OAuth / 用户自己的 Token，MVP 阶段只生成脚本由用户自己执行；
2. **不自动代投** —— 只做到"一键填充 + 草稿已填"，最终提交那一下永远由用户自己点；
3. **能力缺口不代填** —— 岗位要求里用户真没做过的，只标注缺口并给出补法，简历里没有的事实不猜。

项目永远是**陪练**，不是代打。

## 功能

| 模块 | 说明 |
|------|------|
| 我的画像 | 基本信息 / 技能勾选 / 项目列表；**从项目描述自动推断能力**，点击确认即勾选 |
| 项目方向推荐 | 按画像匹配方向，给路线图 + 阶段验收追问（答不出 = 还没做完）；附「补强计划」：加强 / 拓展 / 新项目 |
| JD 分析 · 打招呼 | 粘 JD 全文 → 命中关键词 vs 缺口分类（缺口**自动排除在招呼语外**）→ 生成初稿（可选 AI 润色） |
| 投递台账 | 投递记录 + 状态统计 + **JD 高频关键词榜**（复习优先级由真实投递数据决定，不凭感觉） |
| 面试备战 | 按方向生成知识清单 / 场景题 / 项目防御题；面经粘贴或链接抓取 → 自动抽题 + 高频考点榜 |
| 简历直填包 | 按 BOSS / 实习僧在线简历的真实表单字段生成文本块，逐块复制粘贴 |

## 快速开始

**方式一（推荐）：** 双击 `start.bat`（Windows），自动打开浏览器。

**方式二：** `node server.js` 后访问 http://127.0.0.1:8321

**方式三（离线）：** 直接双击 `index.html`——除"面经链接抓取"和"AI 润色"外全部功能可用。

### 启用 AI 润色（可选）

在项目目录新建 `llm.json`（兼容所有 OpenAI 格式接口，Key 只存本机）：

```json
{
  "baseURL": "https://api.deepseek.com",
  "key": "sk-你的Key",
  "model": "deepseek-chat"
}
```

保存即生效，无需重启。

### 面经链接抓取

仅支持牛客 `discuss` 链接。`exam` 页在登录态内、`feed` 页不做服务端渲染，均无法抓取——应用会把这一限制明确提示出来，而不是静默失败。

## 测试

零依赖测试套件（`node --test`），覆盖核心逻辑与产品红线，共 **42 条断言**：

| 文件 | 覆盖 |
|------|------|
| `test/guard.test.mjs` | 三不原则：学校名不泄漏、缺口不代填、不编造届数与数字 |
| `test/jd.test.mjs` | JD 关键词命中 / 缺口分类、内部键不泄漏到界面 |
| `test/parse.test.mjs` | 面经抽题、主题高频榜、全量输出不截断 |
| `test/pack.test.mjs` | BOSS / 实习僧直填包字段、实习僧结束月=当前月、业绩栏防编造 |
| `test/plan.test.mjs` | 能力推断、加强 / 拓展 / 新项目三桶计划 |
| `test/repo.test.mjs` | 仓库级安全不变量：密钥不入库、只监听回环、零外链依赖、红线文案双端一致 |

```bash
node --test
```

**单文件应用怎么测**：`test-support/harness.mjs` 把 `index.html` 里的 `<script>` 抽出来，注入桩 DOM / localStorage 后在沙箱中求值，于是全部业务逻辑都能在 Node 里断言，且不破坏「单文件、零构建」的部署方式。

CI 见 [`.github/workflows/test.yml`](.github/workflows/test.yml)。

## 隐私与数据

- 所有画像 / 台账数据存在浏览器 `localStorage`，**不上传任何服务器**；
- `llm.json` 已在 `.gitignore` 中，永远不会被提交；
- 本地服务只监听 `127.0.0.1`，不对局域网开放。
