# offer-pipeline 求职流水线助手

![test](https://github.com/Dongnb66/offer-pipeline/actions/workflows/test.yml/badge.svg)
[后端仓库:agent-platform-java](https://github.com/Dongnb66/agent-platform-java) · 本仓库是它的前端,前后端合起来是一个项目。

从「我是谁」到「面试进场」的本地求职流水线：**画像 → 能力推断 → 方向推荐 → JD 分析 → 打招呼初稿 → 投递台账 → 求职分线 → 面试备战 → 简历直填包（含版本快照与控制台填充脚本）**，一个闭环，数据全部存在本机浏览器。

单文件前端（纯 HTML/CSS/JS，无外部依赖、无框架、无构建）+ 可选零依赖 Node 本地服务（面经抓取 / AI 润色）+ 可选 Spring Boot 后端（[agent-platform-java](https://github.com/Dongnb66/agent-platform-java)，服务端同步与 AI 能力）。

## 为什么做这个

市面上的求职工具分两种：一种帮你"自动化投简历"，一种帮你"把项目做出来"。这两种都有致命问题：

- **自动代投**违反招聘平台用户协议，封号风险由用户承担；
- **平台代做项目**，用户简历上写的是自己答不出设计决策的项目，面试一问"为什么这么选型"就露馅，且全平台项目同质化。

所以本项目立了三条红线（也是产品哲学，见应用内「三不原则」页）：

1. **不收账号密码** —— 将来接推送只走 OAuth / 用户自己的 Token，MVP 阶段只生成脚本由用户自己执行；
2. **不自动代投** —— 只做到"一键填充 + 草稿已填"，最终提交那一下永远由用户自己点；
3. **能力缺口不代填** —— 岗位要求里用户真没做过的，只标注缺口并给出补法，简历里没有的事实不猜。

项目永远是**陪练**，不是代打。

## 功能

| 模块 | 说明 |
|------|------|
| 我的画像 | 基本信息 / 技能勾选 / 项目列表；**从项目描述自动推断能力**，点击确认即勾选；**院校策略开关**——招呼语是否提及学校由你定（默认不提，规避劣势；院校是优势可开「总是提」） |
| 项目方向推荐 | 按画像匹配方向，给路线图 + 阶段验收追问（答不出 = 还没做完）；附「补强计划」：加强 / 拓展 / 新项目 |
| JD 分析 · 打招呼 | 粘 JD 全文 → 命中关键词 vs 缺口分类（缺口**自动排除在招呼语外**）→ 生成初稿（可选 AI 润色） |
| 投递台账 | 投递记录 + 状态统计 + **JD 高频关键词榜**（复习优先级由真实投递数据决定，不凭感觉） |
| 面试备战 | 按方向生成知识清单 / 场景题 / 项目防御题，每条可自评「会 / 不会 / ★」；**知识点配讲解卡（是什么 / 答题要点 / 高频追问），场景题配参考思路**——不会的能点开学，不是只让你自评；**模拟出题（可出 10 / 20 / 30 道，支持换一批）**：薄弱项优先 → 岗位考点命中 → 场景题 → 高频追问，已标「会」的不再出；**内置 130 题 QBANK 题库**（65 单选即点即判 + 65 问答带结构化参考答案，迁移自私有备战站）；面经粘贴或链接抓取 → 自动抽题 + **必考榜分级** + **跨篇高频考点榜**（含 HR/软素质桶）+ 跨方向**薄弱清单**与进度条 |
| 求职分线 | 按方向（Agent / 后端 / 全栈）分线管理岗位池：每条线独立看「岗位数 / 已投出 / 约面」进度条，可从台账一键导入（重复自动跳过） |
| 简历直填包 | 按 BOSS / 实习僧在线简历的真实表单字段生成文本块，逐块复制粘贴 |
| 简历版本快照 | 每次改口径前存一份快照，改崩了一键恢复（快照保留可反复恢复），随备份导出 |
| 控制台填充脚本 | 生成一段粘贴进平台编辑页 F12 控制台的脚本：只填空框和占位框、**绝不点击任何按钮**，检查后由用户自己点保存（不收账号密码、不发网络请求） |
| 数据备份 | 画像 / 台账 / 分线 / 快照 / 复习标记一键导出为 JSON，换设备 / 换浏览器可导入恢复（数据只在本机 localStorage，清浏览器数据会丢） |
| 服务端同步 | 配套 Spring Boot 后端 [agent-platform-java](https://github.com/Dongnb66/agent-platform-java)：备份 JSON 一键推送到本机服务端保存历史快照、跨设备拉回恢复，彻底解决「清缓存丢数据」；后端未运行时自动降级，导出按钮始终可用 |

## 快速开始

**方式一（推荐）：** 双击 `start.bat`（Windows），自动打开浏览器。

**方式二：** `node server.js` 后访问 http://127.0.0.1:8321

**方式三（离线）：** 直接双击 `index.html`——除"面经链接抓取"和"AI 润色"外全部功能可用。

### 启用 AI 润色（可选）

在项目目录新建 `llm.json`（兼容所有 OpenAI 格式接口，Key 只存本机）：

```json
{
  "baseURL": "https://api.deepseek.com",
  "key": "sk-你的Key",
  "model": "deepseek-chat"
}
```

保存即生效，无需重启。

### 面经链接抓取与搜索

面试备战页支持两种收面经的方式：

- **粘贴全文**（离线可用）；
- **贴牛客 `discuss` 链接自动抓取**（需本地服务）——仅支持 `discuss` 链接，`exam` 页在登录态内、`feed` 页不做服务端渲染，均无法抓取，应用会把限制明确提示而不是静默失败；抓取带 10 秒超时。

每篇解析后自动收录进**已收面经库**（重复解析按题目集合签名去重），考点榜跨篇累计——「哪些考点被 3 篇以上面经考到」才是真·P0。「去牛客搜面经」按钮按当前方向拼好搜索词直接开牛客搜索页，发现靠人、提炼靠工具。

## 隐私与数据

- 所有画像 / 台账数据存在浏览器 `localStorage`，**不上传任何服务器**；
- `llm.json` 已在 `.gitignore` 中，永远不会被提交；
- 本地服务只监听 `127.0.0.1`，不对局域网开放；
- 本地服务校验 `Origin`：只有本机页面（含 `file://` 离线打开）能调用——你浏览器里的其他网页无法借用你的 LLM Key。
